## 0. 착수 30분 (제일 먼저, 무조건)

1. **강남 CSV 다운받고 컬럼 실측** ← 1번임
   - `그룹/폐기물명/규격/수수료` 가정이 맞는지 눈으로 확인
   - **`규격` 컬럼 unique 값 전부 뽑기** (`df['규격'].unique()`)
   - 이게 제일 중요함. 규격이 자유텍스트면 그래프 스키마도, VLM 프롬프트도 다 바뀜. 여기 결과가 이후 전부를 결정함
2. **VLM 스모크 테스트 1장** — 소파 사진 아무거나 넣고 JSON 나오는지만 확인. API 키/쿼터/이미지 인코딩 이슈를 지금 터뜨려야 함

> 이 두 개 끝나기 전에 다른 코드 짜지 말기. 여기서 막히면 스코프 전체를 바꿔야 함.

## 0.5. 스키마 동결 (20분)

- 규격 버킷 정의 확정 (예: `소/중/대` or `1m미만/1m이상`) — CSV 실측값에 맞춰서
- VLM 출력 JSON 스펙 문서로 박기: `{품목, 규격버킷, confidence, 근거}`
- repo 파고 CLAUDE.md에 위 스키마 붙이기

**이거 동결 안 하면 나중에 전부 갈아엎게 됨.** 저번 NHN 때처럼 스키마 먼저 얼리는 게 맞음.

## 1. 수직 슬라이스 (2h) ← Day1 최우선

**그래프 만들지 말고** 하드코딩으로:

```
사진 1장 → VLM → {품목:"소파", 규격:"중"} → dict lookup → "12,000원" 출력
```

CLI에서 이거 한 번 돌면 프로젝트 성공 확률 80% 확보임. 안 되면 즉시 스코프 축소.

## 2. 데이터층 (3~4h)

3. CSV 정규화 (품목명 공백/괄호 정리, 수수료 int 캐스팅)
4. 그래프 빌드 (networkx) + pickle 저장
5. 품목명 임베딩 인덱스 (미등재 → 유사품목 top-k)
6. 예외 분기 노드 수동 추가 — 무상수거 가전 목록, 재활용, 종량제, 불연성마대

## 3. LangGraph 배선 (3~4h)

7. 노드 순서: `분류 → 무상수거체크 → 그래프조회 → (miss면 유사추론) → 응답합성`
8. **근거 경로(path)를 state에 계속 실어나르기** ← 이게 데모 핵심. 나중에 붙이면 배선 다시 해야 함
9. confidence 임계값 분기 (낮으면 `needs_confirm: true`)

## 4. UI (4~5h) — Day2 오전

10. 사진 업로드 → 로딩 → 결과카드
11. **규격 셀렉터 먼저 붙이기** (오답 흡수 장치가 데모 안정성의 핵심)
12. 근거 경로 시각화 (텍스트 체인만이라도)

## 5. 마감 (3h) — Day2 오후

13. 샘플 10장 하드테스트 → 깨지는 케이스 하드코딩 방어
14. 면책 문구 + 데이터 기준일 박기
15. 데모 시나리오 3개 고정 (성공 / 미등재→유사추론 / 무상수거 분기) ← 이 3개만 리허설
16. 발표자료

## 체크포인트

- **Day1 종료 시점에 CLI end-to-end 안 되면** → 그래프 버리고 dict lookup으로 다운그레이드. 미련 갖지 말기
- **Day2 시작 시점에 UI 착수 못 했으면** → Streamlit or Gradio로 갈아타기

## 짧은 주의

- 2번(스모크 테스트)에서 VLM이 한국어 품목명을 CSV 표기랑 다르게 뱉을 확률 높음("쇼파" vs "소파", "3인용소파" vs "소파(3인용)"). **정규화 매핑 테이블을 1시간쯤 미리 잡아두는 게 나중에 몇 시간 아낌.**
- 임베딩 유사도만 믿으면 "책상"↔"책장" 같은 거 헷갈림. top-k 후보를 UI에 노출해서 사람이 고르게 하는 게 안전함.
