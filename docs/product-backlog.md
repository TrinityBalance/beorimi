# 제품·데이터 백로그

초기 조사 메모에서 아직 유효한 후속 작업만 모았습니다. 구현 상태 문서는 각 역할 가이드를 따릅니다.

## MVP 다음 우선순위

1. 강남구 공식 대형 폐기물 품목·규격·수수료 데이터를 확보하고 기준일을 기록합니다.
2. 공공데이터와 실제 신고 페이지의 품목·금액 차이를 확인하고 표시 기준을 정합니다.
3. 품목 별칭을 정규화합니다. 예: `쇼파 → 소파`, 제품명 → 공식 신고 품목명.
4. Backend에 품목·규격 조회와 근거 경로를 연결하고 Frontend 데모 수수료표를 제거합니다.
5. 미등재 품목, 폐가전 무상수거, 재활용, 종량제, 불연성 마대 분기를 공식 근거와 함께 구현합니다.

## 품질 평가

- 단일·복수·가림·저조도·잘림 장면과 크기 경계 사례를 포함한 실제 사진 평가 세트를 만듭니다.
- 이미지 속 프롬프트 인젝션, QR 코드, 화면 캡처 공격 샘플을 포함합니다.
- 절대 크기는 기준 물체가 없으면 확정하지 않고 사용자 규격 확인으로 보완합니다.
- VLM confidence만으로 수수료를 확정하지 않고 후보·질문·근거 경로를 함께 표시합니다.

## 운영 정책

- 화면에 데이터 기준일과 “실제 금액은 공식 신고 시 확정” 안내를 표시합니다.
- 이미지·캐시·분석 결과의 보존과 삭제 정책을 확정합니다.
- VLM 비용, 지연 시간, 오류율, SQS DLQ를 관측하고 예산 알림을 설정합니다.
- 실제 신고 시스템은 자동 제출보다 공식 페이지 딥링크를 우선합니다.
