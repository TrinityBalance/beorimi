# 팀 개발 규칙

루트와 역할별 `AGENTS.md`가 우선함.

## 서비스 경계

- Frontend는 Vercel Route Handler만 호출함.
- VLM은 이미지 관찰만 하고, 최종 폐기 판단을 하지 않음.
- 계약은 `shared/**`를 먼저 변경한 뒤 제공·소비 구현을 맞춤.
- 운영 배포는 Vercel + Supabase를 사용함.

## 작업 방식

- 다른 역할의 결정/인터페이스가 필요할 때만 `docs/cowork_ground.md`에 요청함.
- 비밀값·개인정보·실제 자격 증명을 코드/문서/로그에 남기지 않음.
- API·DB·배포 구조 변경 시 관련 테스트와 문서를 같이 갱신함.
