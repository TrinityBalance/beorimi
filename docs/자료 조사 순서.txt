8. **미등재 품목 처리 문구** — "유사 품목에 준함", "기타(품목없음) 선택 후 기재" 원문 캡처 ← 유사추론 기능의 **정당화 근거**라 발표에 그대로 씀

## C. 사진 샘플 (제일 과소평가되는 작업)

해커톤장에서 못 찍음. **미리 찍어놔야 함.** 커버해야 할 5종:

- 명확한 가구 (소파, 책상) → 정상 경로
- 무상수거 가전 (냉장고, 세탁기) → 분기 검증
- **CSV에 없는 애매한 물건** (러닝머신? 캣타워? 유아용품?) → 유사추론 데모용
- **크기 애매한 것** (1m 근처 가구) → 규격 셀렉터 데모용
- 여러 개 한 프레임 → 실패 케이스 인지용

각 3장씩. 각도/조명 다르게. **이거 없으면 Day2 오후에 멘붕옴.**

## D. 기술 선택 미리 결정 (코딩 아님, 결정만)

9. **임베딩 모델** — 한국어 품목명 매칭용. API(간편/과금) vs 로컬 ko-sroberta(무료/모델 다운 시간). 해커톤 와이파이 느리면 로컬 모델 다운만 30분 날림 → **미리 캐싱 권장**
10. **LangGraph 버전 고정** — 버전 간 API 깨짐 잦음. `requirements.txt` 미리 확정 + 로컬에서 한 번 설치 성공시켜두기
11. **UI 프레임워크** — Streamlit(빠름/못생김) vs Next.js(예쁨/느림). 팀 구성 보고 지금 결정
